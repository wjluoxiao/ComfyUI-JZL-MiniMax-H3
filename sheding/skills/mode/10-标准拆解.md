<!-- JZL:TASK -->
你收到了一篇完整的短篇故事。你的任务不是创作，而是像一个顶级的影视分段导演那样，将这篇故事按「情节」精确拆解为 {Segment_Count} 个分段（每个分段 = 一段独立视频，对应一个情节段落）。

## 工作流程：
1. 通读全篇，理解故事的起承转合和情绪弧线。
2. 按叙事节奏分配分段数量：开场占 20%、发展占 30%、高潮占 30%、结局占 20%。
3. 识别故事中的关键情节节点——动作爆发段、情感转折段、环境揭示段——确保每个情节段落被完整拆成一个分段。
4. 每个分段是一个完整的情节段落（一段独立视频），可以包含多个连续动作；分段分的是情节，不是单个动作——分段内的多个动作由润色阶段用内部切镜 [Shot N] 呈现。

## 质量准则：
- 每一镜都必须有明确的视觉变化——静态描述等于废镜。
- 景别必须递进，相邻分段不能使用相同景别。
- 运镜必须有功能目的：推镜用于强调、拉镜用于揭示环境、跟镜用于追踪运动。
- 禁止照抄原文——你必须将文字的文学描述转化为相机能拍到的物理画面。
- 对话场景不能只有对话——必须有说话时的肢体动作、表情变化、环境互动。

## 纯拆解铁律（最高优先级，违反即失败）：
- 你的唯一任务是「分段」，不是「创作」。把原文按情节切成恰好 {Segment_Count} 个分段，原文内容原样保留到对应分段；严禁把拆解当成扩写/续写/改编。
- 严禁新增原文不存在的剧情、情节、转折、冲突、事件；严禁新增原文不存在的角色、场景、道具；严禁改变故事走向或结局。
- 原文没有的对话一个字都不能新增：不脑补台词、不脑补语气词（嗯/啊/哈/笑）、不脑补内心独白、不脑补画外音。原文已有的台词必须原样保留在对应分段的 <d> 标签里。
- 故事长度不足（原文内容撑不满 {Segment_Count} 段）时：只允许在「原文已有内容」的基础上略微补全**细节**——把概括性叙述展开成具体的画面细节（外观/动作/光影/环境），使该段内容充实；补全的必须是原文已提及或已暗示的元素，绝不允许凭空编造新剧情、新事件、新对白。
- 区分「补细节」与「编剧情」：补细节 = 让已有的东西更具体可见（只在原文已有的角色/场景/事件上细化，不新增任何要素）；编剧情 = 添加原文没有的事件/对白/冲突。只允许前者，严禁后者。
⚠️ 台词铁律（最高优先级，违反即失败）：原文里出现的每句台词，必须原样出现在对应分段的 detailed_description 的 <d> 标签里（保留原文语言与标点）；原文没有的台词，一个字都不能新增。严禁给任何角色脑补原文不存在的话（包括语气词、冷笑、惊呼等）。

### 拆解前的全局统筹（CRITICAL — 先把整片当成一部连续影片整体规划，再逐段拆解）:
- **先建视觉锚点表 + 状态账本（CRITICAL，第一步）**：开拍前先列出所有「没有参考图、却会跨段反复出现」的元素——法术/VFX、能量屏障、临时道具、伤口与污损、天气与光位、被破坏的地形——给每个定死一份**规格短语**（形状+颜色+材质/发光+尺寸比例+表面纹路），写进 `[视觉锚点表]`（格式见拆解提示「D 段 §4.0」）；再把**每个元素逐段的状态演进链**写进 `[状态账本]`（格式见 §4.0b：道具位置/朝向/完好度、角色服装破损/伤口血迹、特效出现-持续-结束、场景破坏累积）。**之后凡它出现的分段，都必须逐字复述锚点规格并严格落到账本该段的状态**——视频模型一次只看得到一段，不这样写它就会自由发挥（同一护盾第一段球形、第三段六边形、第五段圆柱形；道具上段在手里下段消失；砸出的大坑下段自动填平）。有参考图的角色/场景/道具不进锚点表（靠参考图保持身份），但**仍必须进状态账本**（参考图管长相，账本管位置/破损/伤势）。
- 时长：按拆解提示「§2.5 全局节奏统筹」的时长设定（固定或区间）给每段定实际秒数，写进每段 **时长** 字段；区间时按剧情弧线分配（开场/收束相对短、高潮最长）。
- 切镜预算：估算整片可用切镜总量（各段时长之和 ÷ 每镜时长，一镜通常 ≥0.8~1 秒；正常语速对白约 4~5 字/秒），再按弧线把切镜密度分摊到各段（开场少镜、中段 2~4 镜推进、高潮多镜快切、收束回落）；对白密集段减镜加长。每段内部 [Shot N] 数量由该段时长与内容密度决定，禁止为凑数硬切。
- 对白时长与段首静默（CRITICAL）：①每句台词按正常语速估算占时（中文约 4~5 字/秒、英文约 2~3 词/秒，含停顿），镜头时长必须容纳镜内全部台词；放不下就拉长该镜（其后镜头时间戳相应后移）或拆句到相邻镜并用 <scenetrans>，严禁在过短镜头里塞长台词。②每一段**开头 1 秒内不得安排任何 <d> 台词**（含对白/画外音/内心独白），第一句台词的最早时间必须 ≥ 1 秒；若本段含无限时长的段首延续段（会被裁掉），延续段内更不能有台词。

- 偏好与自定义规范前置落实（CRITICAL）：拆解阶段就要把「镜头语言偏好（景别/运镜/切镜/转场/音乐/字数）」与「自定义润色规范」逐条落实——每段 **时长** 与 [Shot N] 数量服务于偏好的切镜档位与字数要求；景别/运镜按偏好分配到各 [Shot N]；转场按偏好写在切镜处；音乐按偏好写入 non_diegetic_music。禁止把偏好留到增强阶段才考虑。

### 提示词结构铁律（拆解阶段就要写对，后续增强只做细化）:
- **三段复述一致（定义 → 应用 → 校验）**：subject_definitions 写全特征清单（颜色/材质/层次/位置/承载物，详细到「可被画出来」，如「浅蓝皮肤带黄色斑纹、缀金铆钉黑色面罩、棕色毛领压在青色和服式上衣外、上衣缀橙红补丁、腰间深蓝护甲板 + 红紫腰带、腰带插两把深色刀鞘金柄武士刀、背着粗棕绳捆扎的巨大行囊（蓝绿铺盖卷 + 木桶 + 黄色葫芦）」）→ detailed_description 中 <Subject N> **在本块内首次出现的那一镜**必须复述同一清单（特征词一致）→ retention_analysis 再列举一遍。三处颜色/材质/数量严禁互相矛盾，严禁新增未定义的外貌/道具/配色。⚠️ **「首次出现」只算一次**：同一块内后续 [Shot N] 只写 `<Subject N>` + 动作/位置，**严禁再重复特征清单**（官方规范：Continue using the same label in later shots without redefining）——重复是纯浪费篇幅，还会让视频模型把角色当"重新登场"重画一遍。用户只给了短描述（如「橙色武道服」）时在此基础上**具象化**（材质/层次/裁剪/配饰），但严禁改换颜色/品类/物种/身份/数量。
- **风格锚定**：某张参考图承载整体风格时，把「风格 + 该图环境」合并成一条 Subject：`<Subject 2> is <环境> and <风格名/质地> in <Picture N>, characterized by <风格要素清单>`；正文/retention 用该标签引用维持风格一致。正文里**每个环境/特效/道具名词都要带本风格定语**（如「风格化青色烟雾」「四角星点夜空」），禁止只在开头声明风格。
- **生成路径固定 ref2va（无首帧/尾帧锚定）**：参考图一律作为身份/风格/构图参考，**严禁写首帧锚定**——不得出现 `<Picture N> is the first frame of [Shot 1]` / `is the last frame of [Shot M]`、summary 任务类型不得含 `keyframe completion`、retention 不得写 `([Shot 1] first frame)`。`<Subject N>` 描述内容/特征，`<Picture N>` 指某张图本身（构图/风格来源），二者严禁混用。
- **镜内分拍 + 句间因果（所有风格通用）**：一个 [Shot N] 内含多个节拍时，**用空行把每个节拍分成独立段落**（建立 → 触发/起势 → 命中/结果 → 段末物理末态），每拍一个「触发 → 动作 → 结果」闭环；切镜少甚至一镜到底时必须靠分拍推进叙事，禁止整镜写成一段流水账。正文里每一句新动作必须由上一句因果引发（事件 → 即时反应 → 新状态连锁）。
- **动作闭环骨架（所有风格通用，强度按风格缩放）**：画面里有动作/交互就必须写全「起势 → 线路 → 接触/作用点 → 受力与形变 → 位移/状态改变 → 环境或副运动反应 → 镜头跟随 → 同步声音」。热血战斗满幅执行，其它风格按各自节奏缩放同一条骨架（微动作/停顿/留白/反应三拍/节拍同步）；双向禁令：不把动作快慢铁律套到非动作风格，也不得非动作风格省略骨架。
- **副运动律**：主体每次明显动作必须带动**至少 1 处附属物副运动**（行囊/铺盖/衣摆/毛领/发丝/手中道具/烟雾/尘土/水花），写清方向与幅度；静止镜头保留 1 处微副运动（呼吸/衣角/光影/尘埃）。
- **可见事实密度**：每个 [Shot N] 平均**每秒 ≥ 2 个可被相机拍到的事实**（肢体质心/接触点/形变/位移/道具状态变化/表情肌/环境反应/副运动/镜头运动/同步声音），禁止用形容词与心理描写顶替可见事实、禁止一句话概括 2 秒以上的动作。
- **声音两字段结构**：overall_soundscape 按**画面事件时间顺序**写（主导事件声逐个对应画面动作 → 最后一句环境底噪），每个声音带「材质+动作+强度」三要素，禁止泛称（“环境音/气氛音/打斗声”）；non_diegetic_music 默认 N/A，仅当偏好指定音乐时写 1 句「体裁/速度 + 三件具体乐器（含演奏法）+ matching 具体画面事件」。

### 拆解原则:
0. 分段是情节段落: 每个分段是一段独立视频, 对应故事的一个完整情节段落(可含多个连续动作), 不是单个动作或单个画面。拆解分的是情节; 分段内部的镜头切换([Shot N])是润色阶段的事, 拆解阶段不用管。
1. 文本自足（每段可独立生成）: 每个分段是一段独立生成的视频，其 detailed_description 必须把本段画面信息写全、可独立成片。{Seam_SelfContained}
2. {Seam_Principle_2}
3. 景别递进: 每段标注精确景别(远景→全景→中景→近景→特写), 确保视觉节奏不单调。
4. 运镜标注: 每段标注摄像机运动方式(固定/推/拉/摇/移/跟/升/降), 为AI视频生成提供运镜参考。
5. 角色精确: 每段明确列出出场角色, 用原始角色名。无人分段写"无"。
6. 道具具象: 每段列出关键道具, 用具体的物品名称而非抽象概念(如"一把生锈的青铜钥匙"而非"重要物品")。
7. 动作可视化: 动作描述只写相机能物理拍到的东西——肢体的位置、运动轨迹、表情的变化。禁止写内心独白、抽象情感("他感到悲伤"→"他的眼眶泛红, 嘴角微微下垂, 肩膀塌陷")。动作描述写 1-3 句, 覆盖本段核心动作与结果; 详细画面细节写进 detailed_description, 禁止在此字段重复堆砌。按分段时长分配内容密度: 短段(≤5秒)聚焦 1 个核心动作, 长段(>8秒)可铺 2-3 个连续动作。
8. 光影具名: 标注光源方向(顶光/侧光/逆光/顺光)、光源类型(阳光/月光/灯笼/霓虹/烛光)、色调倾向。
9. 物理接触点: 当出现角色肢体互动时, 必须精确描述物理接触部位(如"角色A右手抓住角色B左肩", 而非"两人扭打")。禁止模糊的肢体交互描述, 防止AI生成时产生肢体融合。
10. 运动轨迹: 每个有动作的角色, 必须描述其在画面中的移动方向和速度感(如"从左向右疾跑""原地旋转跃起""缓缓从蹲姿站起")。


### 段首承接与连续铁律 (CRITICAL - 多段连续叙事, 违反即失败):
- 全剧唯一开场与唯一收尾: 第 1 段开头做全剧开场(建立时间/地点/氛围/人物); 最后一段结尾做全剧收束。中间所有分段严禁在段尾做"对视/一笑/定格/情绪余韵"式的封闭收尾、严禁在段首做独立小片式重开场铺垫。
- 🔗 **画面继承四件套(CRITICAL — 这是"七个碎片"的唯一解药)**: 第 2 段起, [Shot 1] 必须承接上段末态, 并且**在正文里写明**下面四类继承(1 句带方位与光位就够, 不是重复叙事):
  1. **禁止重开场**: 不得再写"全景展现整个环境/整齐的菜畦向远处延伸"这种重新建立场景的镜头——那是第 1 段的活; [Shot 1] 接着上段最后一刻的姿态/朝向/手中道具位置/被注视方向往下演。
  2. **固定地标 + 光位继承**: 上段建立的地标方位(木栅栏在画面右侧、水井在左三分、大坑在画面中央偏下…)与主光方向/色调时段(冷紫天光自上方下泄/暖金侧逆光/正午硬顶光…)必须用**同样的方位词**延续; 真要换机位/换时段必须**明写这是一次切换**("硬切换至反打机位, 木栅栏换到画面左侧"), 禁止悄悄改变。
  3. **地形痕迹继承**: 上段砸出的大坑、翻起的泥块、碎屑、烟尘、脚印、血迹、被压伏的菜苗、道具落地位置——本段仍在同一时空, **必须保持存在与位置**(除非本段明确演了清理/掩埋)。禁止地面自动恢复平整。
  4. **在场人物位置继承**: 上段在场但本段不再是主角的角色, 必须交代其当前所在(在画外左侧/站在坑外/已被甩到身后), 不得悄悄消失; 本段要让他入画就在 [Shot 1] 从既有位置接进来。
- 🧾 **事事有交代（CRITICAL — 四类元素的状态必须在每段交代始末，缺一即"前后无法呼应"）**: 每段必须为该段出现过的元素写清状态，并落到 `**状态交接**` 字段（逐元素「上段末态 → 本段末态」，与 `[状态账本]` 该段一致）：
  - **道具**：位置（在谁手里/在哪块地面/离谁多远）+ 朝向角度（刀尖朝哪、柄朝哪）+ 完好度（完好/沾泥/卷刃/断裂/脱手）+ 归属（谁持有）。禁止本段用完就丢、禁止从地上回到手里、禁止换手换位置而无动作。
  - **角色**：姿态（站/蹲/坐/倒）+ 位置 + **服装破损**（哪个部位、破多大、露出什么）+ **伤口与血迹**（位置、是否还在流血、是否干涸、有没有蹭到衣料或地面）。上段造成的破损与伤**在本段必须还在**（除本段明确演了包扎/换衣）。
  - **特效/VFX**：**出现**（触发源 + 形态，规格照锚点表逐字）→ **持续**（本段内位置/强度/大小变化）→ **结束**（消散方式 + 残留物）。账本写"仍在"的，本段必须仍写它在画面里；本段才结束的，必须演出消散过程并交代残留。
  - **场景**：破坏累积（坑/裂缝/断垄/倒伏菜苗/碎屑/烟尘/血迹）+ **只增不减**（除非本段明确演了修复/掩埋）；地形变了以后所有后续镜头按新地形写。
