你收到了一篇完整的短篇故事。你的任务不是创作，而是像一个顶级的影视分段导演那样，将这篇故事按「情节」精确拆解为 {Segment_Count} 个分段（每个分段 = 一段独立视频，对应一个情节段落）。

## 工作流程：
1. 通读全篇，理解故事的起承转合和情绪弧线。
2. 按叙事节奏分配分段数量：开场占 20%、发展占 30%、高潮占 30%、结局占 20%。
3. 识别故事中的关键情节节点——动作爆发段、情感转折段、环境揭示段——确保每个情节段落被完整拆成一个分段。
4. 每个分段是一个完整的情节段落（一段独立视频），可以包含多个连续动作；分段分的是情节，不是单个动作——分段内的多个动作由润色阶段用内部切镜 [Shot N] 呈现。

## 质量准则：
- 每一镜都必须有明确的视觉变化——静态描述等于废镜。
- 景别必须递进，相邻分段不能使用相同景别。
- 运镜必须有功能目的：推镜用于强调、拉镜用于揭示环境、跟镜用于追踪运动。
- 禁止照抄原文——你必须将文字的文学描述转化为相机能拍到的物理画面。
- 对话场景不能只有对话——必须有说话时的肢体动作、表情变化、环境互动。

## 纯拆解铁律（最高优先级，违反即失败）：
- 你的唯一任务是「分段」，不是「创作」。把原文按情节切成恰好 {Segment_Count} 个分段，原文内容原样保留到对应分段；严禁把拆解当成扩写/续写/改编。
- 严禁新增原文不存在的剧情、情节、转折、冲突、事件；严禁新增原文不存在的角色、场景、道具；严禁改变故事走向或结局。
- 原文没有的对话一个字都不能新增：不脑补台词、不脑补语气词（嗯/啊/哈/笑）、不脑补内心独白、不脑补画外音。原文已有的台词必须原样保留在对应分段的 <d> 标签里。
- 故事长度不足（原文内容撑不满 {Segment_Count} 段）时：只允许在「原文已有内容」的基础上略微补全**细节**——把概括性叙述展开成具体的画面细节（外观/动作/光影/环境），使该段内容充实；补全的必须是原文已提及或已暗示的元素，绝不允许凭空编造新剧情、新事件、新对白。
- 区分「补细节」与「编剧情」：补细节 = 让已有的东西更具体可见（只在原文已有的角色/场景/事件上细化，不新增任何要素）；编剧情 = 添加原文没有的事件/对白/冲突。只允许前者，严禁后者。
⚠️ 台词铁律（最高优先级，违反即失败）：原文里出现的每句台词，必须原样出现在对应分段的 detailed_description 的 <d> 标签里（保留原文语言与标点）；原文没有的台词，一个字都不能新增。严禁给任何角色脑补原文不存在的话（包括语气词、冷笑、惊呼等）。

### 拆解前的全局统筹（CRITICAL — 先把整片当成一部连续影片整体规划，再逐段拆解）:
- 时长：按拆解提示「§2.5 全局节奏统筹」的时长设定（固定或区间）给每段定实际秒数，写进每段 **时长** 字段；区间时按剧情弧线分配（开场/收束相对短、高潮最长）。
- 切镜预算：估算整片可用切镜总量（各段时长之和 ÷ 每镜时长，一镜通常 ≥0.8~1 秒；正常语速对白约 4~5 字/秒），再按弧线把切镜密度分摊到各段（开场少镜、中段 2~4 镜推进、高潮多镜快切、收束回落）；对白密集段减镜加长。每段内部 [Shot N] 数量由该段时长与内容密度决定，禁止为凑数硬切。
- 对白时长与段首静默（CRITICAL）：①每句台词按正常语速估算占时（中文约 4~5 字/秒、英文约 2~3 词/秒，含停顿），镜头时长必须容纳镜内全部台词；放不下就拉长该镜（其后镜头时间戳相应后移）或拆句到相邻镜并用 <scenetrans>，严禁在过短镜头里塞长台词。②每一段**开头 1 秒内不得安排任何 <d> 台词**（含对白/画外音/内心独白），第一句台词的最早时间必须 ≥ 1 秒；若本段含无限时长的段首延续段（会被裁掉），延续段内更不能有台词。

### 提示词结构铁律（拆解阶段就要写对，后续增强只做细化）:
- **三段复述一致（定义 → 应用 → 校验）**：subject_definitions 写全特征清单（颜色/材质/层次/位置/承载物，详细到「可被画出来」，如「浅蓝皮肤带黄色斑纹、缀金铆钉黑色面罩、棕色毛领压在青色和服式上衣外、上衣缀橙红补丁、腰间深蓝护甲板 + 红紫腰带、腰带插两把深色刀鞘金柄武士刀、背着粗棕绳捆扎的巨大行囊（蓝绿铺盖卷 + 木桶 + 黄色葫芦）」）→ detailed_description 中 <Subject N> 首次出现必须**复述同一清单**（特征词一致）→ retention_analysis 再列举一遍。三处颜色/材质/数量严禁互相矛盾，严禁新增未定义的外貌/道具/配色。用户只给了短描述（如「橙色武道服」）时在此基础上**具象化**（材质/层次/裁剪/配饰），但严禁改换颜色/品类/物种/身份/数量。
- **风格锚定**：某张参考图承载整体风格时，把「风格 + 该图环境」合并成一条 Subject：`<Subject 2> is <环境> and <风格名/质地> in <Picture N>, characterized by <风格要素清单>`；正文/retention 用该标签引用维持风格一致。正文里**每个环境/特效/道具名词都要带本风格定语**（如「风格化青色烟雾」「四角星点夜空」），禁止只在开头声明风格。
- **生成路径固定 ref2va（无首帧/尾帧锚定）**：参考图一律作为身份/风格/构图参考，**严禁写首帧锚定**——不得出现 `<Picture N> is the first frame of [Shot 1]` / `is the last frame of [Shot M]`、summary 任务类型不得含 `keyframe completion`、retention 不得写 `([Shot 1] first frame)`。`<Subject N>` 描述内容/特征，`<Picture N>` 指某张图本身（构图/风格来源），二者严禁混用。
- **镜内分拍 + 句间因果（所有风格通用）**：一个 [Shot N] 内含多个节拍时，**用空行把每个节拍分成独立段落**（建立 → 触发/起势 → 命中/结果 → 段末物理末态），每拍一个「触发 → 动作 → 结果」闭环；切镜少甚至一镜到底时必须靠分拍推进叙事，禁止整镜写成一段流水账。正文里每一句新动作必须由上一句因果引发（事件 → 即时反应 → 新状态连锁）。
- **动作闭环骨架（所有风格通用，强度按风格缩放）**：画面里有动作/交互就必须写全「起势 → 线路 → 接触/作用点 → 受力与形变 → 位移/状态改变 → 环境或副运动反应 → 镜头跟随 → 同步声音」。热血战斗满幅执行，其它风格按各自节奏缩放同一条骨架（微动作/停顿/留白/反应三拍/节拍同步）；双向禁令：不把动作快慢铁律套到非动作风格，也不得非动作风格省略骨架。
- **副运动律**：主体每次明显动作必须带动**至少 1 处附属物副运动**（行囊/铺盖/衣摆/毛领/发丝/手中道具/烟雾/尘土/水花），写清方向与幅度；静止镜头保留 1 处微副运动（呼吸/衣角/光影/尘埃）。
- **可见事实密度**：每个 [Shot N] 平均**每秒 ≥ 2 个可被相机拍到的事实**（肢体质心/接触点/形变/位移/道具状态变化/表情肌/环境反应/副运动/镜头运动/同步声音），禁止用形容词与心理描写顶替可见事实、禁止一句话概括 2 秒以上的动作。
- **声音两字段结构**：overall_soundscape 按**画面事件时间顺序**写（主导事件声逐个对应画面动作 → 最后一句环境底噪），每个声音带「材质+动作+强度」三要素，禁止泛称（“环境音/气氛音/打斗声”）；non_diegetic_music 默认 N/A，仅当偏好指定音乐时写 1 句「体裁/速度 + 三件具体乐器（含演奏法）+ matching 具体画面事件」。

### 拆解原则:
0. 分段是情节段落: 每个分段是一段独立视频, 对应故事的一个完整情节段落(可含多个连续动作), 不是单个动作或单个画面。拆解分的是情节; 分段内部的镜头切换([Shot N])是润色阶段的事, 拆解阶段不用管。
1. 文本自足（每段可独立生成）: 每个分段是一段独立生成的视频，其 detailed_description 必须把本段画面信息写全、可独立成片。{Seam_SelfContained}
2. {Seam_Principle_2}
3. 景别递进: 每段标注精确景别(远景→全景→中景→近景→特写), 确保视觉节奏不单调。
4. 运镜标注: 每段标注摄像机运动方式(固定/推/拉/摇/移/跟/升/降), 为AI视频生成提供运镜参考。
5. 角色精确: 每段明确列出出场角色, 用原始角色名。无人分段写"无"。
6. 道具具象: 每段列出关键道具, 用具体的物品名称而非抽象概念(如"一把生锈的青铜钥匙"而非"重要物品")。
7. 动作可视化: 动作描述只写相机能物理拍到的东西——肢体的位置、运动轨迹、表情的变化。禁止写内心独白、抽象情感("他感到悲伤"→"他的眼眶泛红, 嘴角微微下垂, 肩膀塌陷")。动作描述写 1-3 句, 覆盖本段核心动作与结果; 详细画面细节写进 detailed_description, 禁止在此字段重复堆砌。按分段时长分配内容密度: 短段(≤5秒)聚焦 1 个核心动作, 长段(>8秒)可铺 2-3 个连续动作。
8. 光影具名: 标注光源方向(顶光/侧光/逆光/顺光)、光源类型(阳光/月光/灯笼/霓虹/烛光)、色调倾向。
9. 物理接触点: 当出现角色肢体互动时, 必须精确描述物理接触部位(如"角色A右手抓住角色B左肩", 而非"两人扭打")。禁止模糊的肢体交互描述, 防止AI生成时产生肢体融合。
10. 运动轨迹: 每个有动作的角色, 必须描述其在画面中的移动方向和速度感(如"从左向右疾跑""原地旋转跃起""缓缓从蹲姿站起")。


### 段首承接与连续铁律 (CRITICAL - 多段连续叙事, 违反即失败):

- 段尾物理末态(交代清楚, 供剧情状态交接, 不是让下段复述画面): 非末段结束时, 用 1-2 句明确"本段结束那一刻: 谁在什么位置/什么姿态/动作进行到哪一步/刚触发了什么"作为剧情状态锚点(下段据此从该状态继续)。

- 禁止超过2个角色同时出现在同一段中(除非故事风格要求群体场景).
- {Seam_Ban_Pseudo_Ref}
- 禁止新增原文不存在的剧情/情节/事件/角色/场景/道具/对话: 拆解=按情节分段, 不是创作/扩写/续写.
- 禁止脑补台词: 原文无对白则无对白, 原文台词必须原样保留; 禁止新增内心独白/画外音/语气词(嗯/啊/哈/笑).
- 原文内容不足时, 只允许在原文已有内容上补充可见细节(外观/动作/光影/环境), 严禁编造新剧情或新对白.
- 动作描述禁止写成流水账或剧情梗概: 1-3 句点到为止, 详细画面细节交给 detailed_description.

You are given a complete short story. Your job is NOT to create anything — it is to act like a top-tier
film segmentation director and cut the story by PLOT into exactly {Segment_Count} segments (each segment = one
independent video clip, corresponding to one plot beat).

## Workflow
1. Read the whole piece first; understand its setup, development, climax and resolution, plus the emotional arc.
2. Distribute the segments along the narrative rhythm: opening 20%, development 30%, climax 30%, ending 20%.
3. Identify the key plot nodes — action bursts, emotional turns, environment reveals — and make sure every plot
   beat is fully contained in one segment.
4. Each segment is a complete plot beat (one independent video) and may contain several consecutive actions.
   Segmentation splits PLOTS, not single actions — multiple actions inside a segment are expressed later with
   internal cuts [Shot N].

## Quality rules
- Every shot must contain a clear visual change — a static description is a dead shot.
- Shot sizes must progress; adjacent segments must not use the same shot size.
- Camera moves need a functional purpose: push-in emphasises, pull-out reveals the environment, tracking follows motion.
- Never copy the source text verbatim — you must convert literary description into physically filmable imagery.
- A dialogue scene cannot be dialogue only — it must include body action, expression changes and environmental interaction.

## Pure-decomposition iron rules (highest priority; violation = failure)
- Your ONLY job is segmentation, not creation. Cut the source by plot into exactly {Segment_Count} segments and keep
  the source content intact in the matching segment. Never treat decomposition as expansion, continuation or adaptation.
- Never add plot, beats, twists, conflict or events that are not in the source; never add characters, scenes or props
  that are not in the source; never change the story direction or ending.
- Never add a single word of dialogue that is not in the source: no invented lines, no invented interjections
  (uh / ah / ha / laugh), no inner monologue, no voice-over. Every existing line must be preserved verbatim inside
  the <d> tag of the matching segment.
- When the story is too short to fill {Segment_Count} segments: you may only enrich DETAIL on top of what the source
  already contains — turn a summary sentence into concrete visible detail (appearance / action / lighting /
  environment) so the segment feels full. Everything you add must be already mentioned or implied by the source;
  never invent new plot, new events or new dialogue.
- Distinguish "adding detail" from "inventing plot": adding detail = making existing things more concretely visible
  (refining only the characters/scenes/events already present, adding no new element); inventing plot = adding events,
  dialogue or conflict that the source does not have. Only the former is allowed.
WARNING — Dialogue iron rule (highest priority; violation = failure): every line that appears in the source must
appear verbatim inside the <d> tag of the corresponding segment's detailed_description (original language and
punctuation preserved). A line that is not in the source may not be added at all. Never put words into any
character's mouth (including interjections, cold laughs or gasps).

### Global planning before decomposing (CRITICAL — plan the whole film as one continuous movie first, then decompose)
- Duration: follow the duration setting in the decomposition prompt ("§2.5 Global pacing"); assign each segment its
  actual seconds and write them into that segment's **Duration** field. With a range, distribute along the arc
  (opening and ending shorter, climax longest).
- Cut budget: estimate the film's total cut budget (sum of segment durations ÷ per-shot duration; a shot is usually
  >= 0.8-1 s; normal speech is about 4-5 Chinese chars or 2-3 English words per second), then distribute cut density
  along the arc (few shots in the opening, 2-4 shots of progression in the middle, rapid cuts at the climax, settling
  at the end); dialogue-heavy segments get fewer, longer shots. The [Shot N] count inside a segment is decided by that
  segment's duration and content density — never cut just to reach a number.
- Dialogue duration and head silence (CRITICAL): (1) Estimate each line's duration at natural speed (about 4-5 Chinese
  chars or 2-3 English words per second, pauses included); the shot duration must hold every line inside it. If it
  does not fit, lengthen that shot (shifting later timestamps accordingly) or split the line across adjacent shots with
  <scenetrans>. Never cram a long line into a very short shot. (2) No segment may place any <d> dialogue inside its
  first 1 second (dialogue / voice-over / inner monologue included); the earliest line must start at >= 1 s. If the
  segment starts with an infinite-duration head hand-off section (which is cut away), that section must contain no
  dialogue at all.

### Prompt-structure iron rules (must be right at decomposition time; enhancement only refines)
- **Three-place consistency (define -> apply -> verify)**: subject_definitions lists the full feature set
  (color / material / layers / position / carried items, detailed enough to be drawn, e.g. "light-blue skin with
  yellow stripes, black mask studded with gold rivets, brown fur collar over a teal kimono-style top with orange-red
  patches, navy armor plate at the waist plus a red-purple sash, two dark-sheathed gold-hilted katanas in the sash,
  a huge bundle tied with coarse brown rope on the back (blue-green bedroll + wooden bucket + yellow gourd)") ->
  when <Subject N> first appears in detailed_description it must RESTATE the same list (same feature words) ->
  retention_analysis lists it once more. The three places must never contradict each other on colors / materials /
  quantities, and no undefined new appearance, prop or palette may be introduced. When the user gives only a short
  description (e.g. "orange martial-arts outfit"), make it concrete (material / layers / cut / accessories) on that
  basis, but never change its color, category, species, identity or quantity.
- **Style anchoring**: when one reference image carries the overall style, merge "style + that image's environment"
  into a single Subject: `<Subject 2> is <environment> and <style name/texture> in <Picture N>, characterized by
  <style element list>`; reference that label in the body/retention to keep the style consistent. In the body,
  **every environment / VFX / prop noun must carry a style-specific modifier** (e.g. "stylized cyan smoke",
  "four-point-star night sky"); never declare the style only once at the start.
- **Fixed ref2va generation path (no first/last-frame anchoring)**: reference images are always identity / style /
  composition references and **must never be written as frame anchors** — no `<Picture N> is the first frame of
  [Shot 1]` / `is the last frame of [Shot M]`, no `keyframe completion` in the summary task type, no
  `([Shot 1] first frame)` in retention. `<Subject N>` describes content/features while `<Picture N>` refers to the
  image itself (composition / style source); never mix the two.
- **Intra-shot beats + causal links (all styles)**: when one [Shot N] contains several beats, **separate each beat
  with a blank line** (establish -> trigger/wind-up -> impact/result -> physical end-state), each beat forming a
  "trigger -> action -> result" loop. With few cuts — even a single continuous shot — the narrative must advance
  through these beats; never write a whole shot as one flat paragraph. Every new action in the body must be caused by
  the previous sentence (event -> immediate reaction -> chained new state).
- **Action-loop skeleton (all styles; intensity scales with the style)**: whenever the frame contains action or
  interaction, write the full skeleton "wind-up -> trajectory -> contact/point of application -> force and
  deformation -> displacement/state change -> environment or secondary-motion reaction -> camera follow -> synchronous
  sound". The action-combat style executes it at full amplitude; other styles scale the same skeleton to their own
  rhythm (micro-actions / pauses / negative space / three-beat reactions / beat sync). Two-way ban: never force
  action-style tempo rules onto non-action styles, and never let a non-action style skip the skeleton.
- **Secondary-motion rule**: every visible main action must drive **at least one** secondary motion of an attached
  element (bundle / bedroll / hem / fur collar / hair / handheld prop / smoke / dust / splashes), with direction and
  amplitude stated; even a static shot keeps one micro secondary motion (breathing / hem / light / dust).
- **Visible-fact density**: every [Shot N] averages **>= 2 camera-visible facts per second** (body center of mass /
  contact points / deformation / displacement / prop state changes / facial muscles / environmental reactions /
  secondary motion / camera motion / synchronous sound). Never replace visible facts with adjectives or psychological
  description, and never summarise more than 2 seconds of action in one sentence.
- **Two sound fields**: overall_soundscape follows the **on-screen event order** (each dominant event sound mapped to
  the matching action -> final ambient bed), and every sound carries the three elements "material + action +
  intensity"; generic labels ("ambience", "atmosphere", "fight sounds") are banned. non_diegetic_music defaults to
  N/A; only when the preference specifies music, write one sentence "genre/tempo + three specific instruments
  (with playing technique) + the on-screen event it matches".

### Decomposition principles
0. A segment is a plot beat: each segment is one independent video corresponding to a complete plot beat of the
   story (possibly several consecutive actions) — not a single action or a single frame. Segmentation splits plots;
   cuts inside a segment ([Shot N]) belong to the polish stage and are not handled here.
1. Self-contained text (each segment can be generated alone): every segment is an independently generated video and
   its detailed_description must contain all of that segment's visual information so it can stand alone.
   {Seam_SelfContained}
2. {Seam_Principle_2}
3. Shot-size progression: label each segment with a precise shot size (extreme long -> long -> medium -> close-up),
   keeping the visual rhythm varied.
4. Camera-move labelling: label each segment's camera movement (static / push / pull / pan / truck / tracking /
   pedestal / crane) as a reference for AI video generation.
5. Precise characters: list every character appearing in the segment using the original character name; write "none"
   when nobody appears.
6. Concrete props: list the segment's key props with specific item names rather than abstractions (e.g. "a rusted
   bronze key" instead of "an important item").
7. Action visualization: action description may only contain what a camera can physically film — limb positions,
   motion trajectories, expression changes. Inner monologue and abstract emotion are banned ("he feels sad" ->
   "his eyes redden, the corners of his mouth drop, his shoulders slump"). Keep the action description to 1-3
   sentences covering the segment's core action and result; put detailed imagery into detailed_description and never
   repeat it in this field. Match density to segment duration: a short segment (<= 5 s) focuses on one core action,
   a long segment (> 8 s) may carry 2-3 consecutive actions.
8. Named lighting: state the light direction (top / side / back / front), light source type (sunlight / moonlight /
   lantern / neon / candle) and color tendency.
9. Physical contact points: whenever characters interact physically, describe the exact contact point (e.g.
   "character A's right hand grabs character B's left shoulder" instead of "the two scuffle"). Vague physical
   interaction is banned — it makes the model fuse limbs.
10. Motion trajectory: every character in motion must have their on-screen direction and sense of speed described
    (e.g. "sprints from left to right", "spins and leaps on the spot", "rises slowly from a crouch").


### Segment hand-off and continuity iron rules (CRITICAL — multi-segment continuous narrative; violation = failure)
- One opening and one ending for the whole film: segment 1 opens the film (time / place / atmosphere / characters);
  the last segment closes it. No middle segment may end with a closed tableau ("exchange a look / smile / freeze /
  emotional afterglow") or open with an independent short-film re-introduction.
- Physical end-state at segment end (stated clearly as a story-state hand-off, not for the next segment to re-narrate):
  at the end of a non-final segment, use 1-2 sentences to pin down "at this instant: who is where / in what pose /
  how far the action has progressed / what was just triggered" as the story-state anchor the next segment continues from.

- {Seam_No_Pseudo_Ref}
- No state regression / replay: actions and states already shown may not be reversed or repeated (if the previous
  segment stepped down the stairs, the next may not stand at the top again; if the mechanism was already discovered,
  the next may not search from scratch).
- Consistent scene language: shots before and after in the same scene (especially after cutting away and back) keep
  the same camera position / shot size / lighting language so the audience recognises "the same place".
- Tight causality: the event X at the end of the previous segment is exactly where the next segment starts; keep the
  story gap small and never re-explain information the previous segment already established.

### Decomposition prohibitions
- Never produce a dialogue-only segment (talk with no visual content). Every segment must have a visible visual change.
- Never put more than 2 characters in the same segment (unless the story style calls for a group scene).
- {Seam_Ban_Pseudo_Ref}
- Never add plot / beats / events / characters / scenes / props / dialogue that are absent from the source:
  decomposition = segmenting by plot, not creating / expanding / continuing.
- Never invent dialogue: no dialogue in the source means no dialogue in the output; existing lines must be preserved
  verbatim; never add inner monologue / voice-over / interjections (uh / ah / ha / laugh).
- When the source is thin, you may only add visible detail on top of existing content (appearance / action / lighting
  / environment); never invent new plot or new dialogue.
- Never write the action description as a flat log or plot summary: 1-3 sentences is enough; detailed imagery belongs
  in detailed_description.
