# skill 说明（节点表面与下拉框下方显示的一句话简介）
# 一行一条，格式： 文件名（或短名） = 说明
# 说明控制在 10~40 个字，讲清「这个 skill 到底能做什么」。
# 新增 skill 时在这里补一行即可；没写说明的 skill 会显示「（暂无说明）」。

01-单人替换 = 把视频里那一个主体人物整体换成参考图中的人，全身换、背景路人不动
02-多人替换 = 视频里有几个人就接几张定妆图，逐一对位替换，人数和站位都不变
03-单物替换 = 只把视频里那一件指定物品换成参考图中的物品，人物与场景全保留
04-多物替换 = 视频里多件物品分别换成各自对应的参考图，其他道具保持原样
05-动物替换 = 把视频里那只主体动物整只换成参考图中的动物，毛色花纹全部替换
06-动物换人 = 用参考图中的动物替换视频里的那个人，由动物演绎他的动作与姿态
07-人换动物 = 用参考图中的人物替换视频里的那只动物，人物按原路线与节奏演绎
08-死物替换 = 用参考图中的玩具/玩偶/机器人等替换主体，保持材质，不画成真人
09-背景替换 = 参考图放一张场景图，只换背景环境，前景人物动作构图 100% 保留
10-人物换装 = 只换指定衣物，人物的脸、发型、身材、动作与背景全部保持不变
11-人物换脸 = 只换面部身份，原有的发型、头饰、身材与全身服装全部保留
12-动作迁移 = 原片只当动作/表情/口型/运镜的驱动，外观与场景全丢弃重来
13-风格转绘 = 内容动作构图不变，整片画风笔触材质色彩全部转成参考图的风格
14-物体消除 = 把画面里的干扰物（路人/电线/杂物/Logo）无痕抹掉并补全背景
15-素模渲染 = 红白模、灰模、骨骼预演或线稿视频，渲染成有材质光影的完整成片
16-材质替换 = 只换物体表面材质（金属/水晶/陶瓷/毛绒…），形状与形变完全不动
17-组合编辑 = 一次做多件事（换人＋换背景＋加道具），每件事都能单独声明保留程度
18-添加物体 = 往画面里新增一个物体，原有的人物道具背景一切不动，只增不换
19-人物消失 = 把指定的人从画面里彻底抹掉只留背景，连他的影子反光一起移除
20-局部移除 = 去掉帽子眼镜口罩首饰纹身水印字幕，并还原被它遮住的部分
21-黑白上色 = 把黑白或泛黄老片上成自然彩色，保留颗粒划痕，不做高清修复
22-氛围改造 = 同一场景只改光照与氛围（昼夜/雨雪/色温/霓虹），场景实体零位移
23-口播修改 = 换掉出镜说话的人，用参考音频的音色重说，口型按参考音频对齐
24-唱歌修改 = 换掉开唱的人，用参考音频的音色重唱，口型跟着参考音频走
